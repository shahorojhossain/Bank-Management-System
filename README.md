# Bank Management System

A console-based Bank Management System developed in C++ for a Software Development Project.

## Features

- Account Creation
- Account Information & Balance Check
- Update Account Information
- PIN Number Update
- Deposit
- Withdrawal
- Fund Transfer
- Mini Statement
- Transaction History
- Account Closure
- Admin Records View with Password Protection

## CRUD Operations

- **Create:** Account Creation
- **Read:** Account Information, Balance Check, Admin Records
- **Update:** Account Information and PIN
- **Delete:** Account Closure

## Technologies Used

- C++
- Code::Blocks
- File Handling
- Console Application
- CRUD Operations

## Project Structure

```text
Bank Management System
│
├── main.cpp
├── account.cpp
├── account.h
├── transaction.cpp
├── transaction.h
└── Bank Management System.cbp
```

## Data Storage

The system uses text files to store account and transaction data:

- `accounts.txt`
- `transactions.txt`

These files are created and updated by the program when the system is used.

## Admin Access

The Admin Records View is protected by an admin password.

## How to Run

1. Open the `Bank Management System.cbp` file in Code::Blocks.
2. Build the project.
3. Run the program.
4. Use the main menu to access the available banking operations.
